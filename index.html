แถวแรก = หัวตาราง (เลข 1–18 หรือ สป.1–18) • ต้องมีคอลัมน์ รหัสประจำตัว หรือ ชื่อ-สกุล เพื่อจับคู่กับนักเรียนในตาราง • ช่องที่มีคะแนนจะถูกตั้งเป็น “ส่งงานแล้ว” ให้อัตโนมัติ

นำเข้าคะแนนจิตพิสัย

จับคู่นักเรียนด้วย ชื่อ-สกุล (หรือรหัสประจำตัวถ้ามี) • ค่าที่ใช้ = ตัวเลขตัวสุดท้ายของแต่ละแถว (คอลัมน์ “จิตพิสัย/คะแนนรวม”)

  • คลิกช่อง = สลับสถานะ (ว่าง → เส้นทแยง → ระบายสามเหลี่ยมบน)
  • พิมพ์ตัวเลขมุมล่างขวาของช่อง = คะแนนของช่องนั้น
  • คลิกขวาที่ช่อง = เมนูล้างช่อง / แก้คะแนนเต็ม / ตั้งทั้งคอลัมน์ / ลบนักเรียน / วันหยุด …
  • คลิกเลขหัวสัปดาห์ (1–18) = ตั้งทั้งคอลัมน์ให้ทุกคน ครั้งที่ 1 → มอบหมายงาน · ครั้งที่ 2 → ส่งงาน + ใส่คะแนนเต็ม · ครั้งที่ 3 → ล้าง
