# แบบบันทึกความก้าวหน้าทางการเรียน (Progress Chart)

โปรแกรมกรอกแบบบันทึกความก้าวหน้าทางการเรียน (Progress Chart) ของวิทยาลัยเทคนิคศรีสะเกษ
เป็นไฟล์ HTML ไฟล์เดียว เปิดด้วยเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้ง ทำงานออฟไลน์

## การใช้งาน

เปิดไฟล์ [`index.html`](index.html) ด้วย Google Chrome หรือ Microsoft Edge

หรือใช้งานผ่านเว็บ: **https://wpoosommai.github.io/progress-chart/**
(ต้องเปิด GitHub Pages ในหน้า Settings ของ repo ก่อน)

📘 **คู่มือใช้งานแบบละเอียด:** [`manual.html`](manual.html) — เปิดในเบราว์เซอร์ (13 หัวข้อ ตั้งแต่เริ่มต้นจนถึงการนำเข้าข้อมูลและการพิมพ์)

## ความสามารถ

- **ตารางความก้าวหน้า 18 สัปดาห์** — คลิกช่องเพื่อสลับสถานะ: ว่าง (ขาดเรียน) → เส้นทแยง (มอบหมายงานแล้ว) → ระบายสามเหลี่ยม (ส่งงานแล้ว) พร้อมกรอกคะแนนมุมล่างขวา
- **คลิกเลขหัวสัปดาห์** = ตั้งทั้งคอลัมน์ให้นักเรียนทุกคนพร้อมกัน
- **คลิกขวา** = เมนู (ล้างช่อง / แก้คะแนนเต็ม / ตั้งทั้งคอลัมน์ / ลบนักเรียน / วันหยุด / เพิ่ม-ย้ายแถว)
- **คอลัมน์จิตพิสัย** รวมเข้ากับคะแนนรวมอัตโนมัติ
- **นำเข้ารายชื่อจาก PDF** — ดึงรายชื่อจากไฟล์ PDF ใบรายชื่อ (แก้ปัญหาการันต์/วรรณยุกต์ที่หายจากการดึงข้อความ)
- **นำเข้าคะแนนจาก Excel** (.xlsx/.csv) — จับคู่นักเรียนด้วยรหัสประจำตัวหรือชื่อ
- **นำเข้าคะแนนจิตพิสัยจาก PDF** — จากแบบสรุปผลการประเมินจิตพิสัย
- **บันทึกเป็น PDF** ผ่านระบบพิมพ์ของเบราว์เซอร์ (จัดหน้า A4 ให้พอดี)
- **บันทึก/เปิดไฟล์ข้อมูล** เป็น `.json` และบันทึกอัตโนมัติในเบราว์เซอร์

## หมายเหตุ

ไฟล์ข้อมูลนักเรียน (`.json`, ใบรายชื่อ `.pdf`, คะแนน `.xlsx`) ไม่ถูกนำขึ้น repo นี้
เพราะเป็นข้อมูลส่วนบุคคล — ดู [`.gitignore`](.gitignore)
